How to Read Totals on This Page

Targeting totals describe recommended action volume, not secured outcomes.

Targeting Score Scale

Band Range Meaning
A Priority 80–100 Highest near-term readiness for outreach or ask progression.
B Priority 60–79 Good target with some timing or relationship considerations.
C Priority Below 60 Needs renewal, stabilization, or stewardship before escalation.

Totals Clarification Notes

  • Recommended ask total is a planning sum.
  • Target counts reflect visible filtered records only.
  • One household can contribute multiple visible records.
  • Target type counts are recommendations, not completed actions.
  • A-priority count is not the same as expected gifts closed.
