How the Risk Score Works

Indicator Rule Weight
Past unpaid pledges Any previous unpaid commitment on file 30 points
Late payment history Average payment delay above 30 days 20 points
Lapsed membership Membership status marked as lapsed 15 points
Declining giving trend Most recent giving lower than prior periods 15 points
Low engagement No recent event, meeting, or stewardship touch 10 points
Stretch ask size Current pledge significantly exceeds prior giving level 10 points

This dashboard is designed for GitHub Pages hosting and uses front-end mock data. Replace the sample dataset in the script with your own JSON export or static data file from Python for a portfolio-specific implementation.
